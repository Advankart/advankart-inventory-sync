WooCommerce connection

How to get API keys
  1. WordPress admin → WooCommerce → Settings → Advanced → REST API.
  2. Click Add key, description "Inventory Sync", user = an Administrator, permissions Read/Write.
  3. Copy the Consumer key and Consumer secret here (the secret is shown only once). You can also reuse the keys of your local orders app.
